# Plugins
In banager, plugins are declared with `.plugin.sh` and the user is meant to put those plugins in the `$HOME/.config/banager/plugins` directory.
# Development
To make your own plugins, you need to have a `#!banager/plugin` below the `#!/bin/bash` then you must have a name filled for the owner.
> [!IMPORTANT]
> There will be a seperate template repo made for Banager plugins that you will pull from and will be in the docs
