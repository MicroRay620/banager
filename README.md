# banager
banager is a bash plugin manager that can be installed with a simple script.
# Installation
To install banager just run one of the following:
```shell
curl -sSLO https://codeberg.org/RubyRose/banager/raw/branch/main/install.sh && chmod +x install.sh && ./install.sh && rm -rf ./install.sh 
```
or 
```shell
wget -q https://codeberg.org/RubyRose/banager/raw/branch/main/install.sh && chmod +x install.sh && ./install.sh && rm -rf ./install.sh
```
